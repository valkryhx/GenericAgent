# GA 运行环境与依赖清单（2026-10-22）

> 定位：本文件回答“用户自己安装 Python / Node 后，还需要装什么、装哪个版本、哪些依赖可选”。
> 当前发布面只支持 `ga` / `ga ink`（`ga cli` 作为轻量排障入口）；旧 UI 依赖全部移到 `legacy-*` extras，默认不安装。

---

## 1. 推荐基线

| 组件 | 推荐版本 | 项目约束 / 实测 | 说明 |
| --- | --- | --- | --- |
| Python | **3.12.x** | `pyproject.toml`: `>=3.10,<3.14`；`GETTING_STARTED.md`: 推荐 3.11 / 3.12 | 最稳妥的是 **3.12**；不要用 3.14，`pywebview` 等依赖兼容性不足 |
| Node.js | **22.x LTS** | 当前环境实测 `v22.17.0` | Ink UI 使用 Node `>=18` 即可，但仓库基线是 22.x；建议固定 22 LTS |
| npm | **10.x** | 当前环境实测 `10.9.2` | 随 Node 22 安装即可；项目使用 `package-lock.json`（lockfile v3） |
| pip | 不单独限定 | 随 Python 安装 | 建议先 `python -m pip install --upgrade pip` |
| Git | 不单独限定 | 用于 clone / 更新 | Windows 下建议 Git for Windows，并保留 Git Bash |

## 2. 安装顺序

推荐顺序：**Python 核心 → Ink npm 依赖**。Python 和 Node.js/npm 都由用户预装；旧 UI 与机器人依赖只在维护兼容代码时显式安装。

### 2.1 Python 核心

源码开发环境：

```bash
python -m pip install -e .
```

发布 wheel 安装：

```powershell
powershell -ExecutionPolicy Bypass -File .\install_release.ps1 `
  -Wheel .\genericagent-0.1.0-py3-none-any.whl
```

这会安装 `pyproject.toml` 声明的核心运行时依赖，包括 `PyYAML`、`pydantic`、`psutil` 和 `urllib3`。

### 2.2 默认终端 UI（React + Ink）

`install_release.ps1` 会通过已安装的 `ga_cli.__file__` 定位 site-packages，并在其中的 Ink UI 目录执行 `npm ci`。

源码开发环境则在本仓库安装：

```bash
npm install --prefix frontends/ink/ui
```

### 2.3 可选能力

正常使用 `ga` / `ga ink` 不需要任何 UI extra。只有维护旧入口时才安装：

```bash
python -m pip install -e ".[legacy-ui]"   # Streamlit / pywebview / Textual / rich / pillow
python -m pip install -e ".[legacy-qt]"   # PySide6 / markdown
python -m pip install -e ".[legacy-bots]" # Telegram / QQ / Discord / 飞书等
```

MCP 是仍在维护的独立可选能力：

```bash
python -m pip install -e ".[mcp]"
```

### 2.4 检查安装结果

```bash
python --version
node --version
npm --version
python -m ga_cli list
npm --prefix frontends/ink/ui test
npm --prefix frontends/ink/ui run typecheck
```

## 4. Node / TypeScript 依赖

### 4.1 Node 版本

- 推荐：**Node.js 22.x LTS**
- 最低可用：Node.js 18.x（Ink 5 / `tsx` / TypeScript 5 的最低线）
- 不建议：Node 16 及以下
- 仓库当前实测：**Node v22.17.0 / npm 10.9.2**

> `genericagent/workflow/runtime.py` 会直接启动 `node.exe`（Windows）或 `node`（其他平台）执行 `genericagent/workflow/js/worker.js`。因此即使不使用 Ink UI，**workflow 仍要求系统 PATH 中存在 Node**。

### 4.2 根目录 npm 依赖

根目录 `package.json` 只有一个依赖：


| 包 | 新归类 | 原因 |

| `psutil` | 核心 `dependencies` | `ga status`、子代理进程检测与终止 |
| `urllib3` | 核心 `dependencies` | `genericagent/llm/core.py` 显式导入 |

同时新增/调整以下 extras：

| extra | 内容 | 状态 |
| --- | --- | --- |
| `mcp` | `mcp`、`fastmcp` | 受支持 |
| `langfuse` | `langfuse` | 受支持、可选 |
| `legacy-ui` | `streamlit`、`pywebview`、`textual`、`rich`、`pillow` | deprecated |
| `legacy-qt` | `PySide6`、`markdown` | deprecated |
| `legacy-bots` | Telegram、QQ、Discord、微信、飞书、企业微信、钉钉 | deprecated |

### 5.2 `requirements.txt` 的角色

`requirements.txt` 已同步为**当前实测环境的固定版本快照**，用于复现问题或批量部署参考；安装语义仍以 `pyproject.toml` 为准：

```bash
python -m pip install -e .                  # 核心 / ga / ga ink
python -m pip install -e ".[mcp]"           # MCP（可选、受支持）
python -m pip install -e ".[legacy-ui]"     # 旧 Streamlit / Textual / pywebview（deprecated）
python -m pip install -e ".[legacy-qt]"     # 旧 Qt 桌面（deprecated）
python -m pip install -e ".[legacy-bots]"   # 旧聊天平台（deprecated）
```

> `requirements.txt` 中把可选平台依赖保留为注释，避免默认安装时拉入大量无关 SDK。需要固定环境时，取消对应行注释后再安装。

### 5.3 仍需注意

- `pydantic` 使用 v2。若用户环境已有 v1，需要升级；不要把 v1 与 v2 混用。
- `fastmcp` 与 `mcp` 的版本需要和实际 MCP server 配置联调，本文只给出最低版本线。
- 旧 `pywebview` 入口在 Windows 上还需要系统 WebView2 Runtime；正常 `ga` / `ga ink` 不依赖它。
- `PySide6` 体积较大，且旧 Qt 入口已退役，因此只放在 `legacy-qt` extra。
- Node 仍是外部运行时，不由 pip 安装。

## 8. 版本与兼容性注意事项

1. **Python 3.14 不可用。** `pyproject.toml` 明确排除 `>=3.14`，新手文档也说明 `pywebview` 等依赖不兼容。
2. **Node 版本不要低于 18。** Ink 5 和当前 TypeScript 工具链都依赖较新的 Node；推荐 22 LTS。
3. **Windows 上不要用 WindowsApps 的 Python 别名。** 若 `where python` 指向 `WindowsApps`，请安装 python.org 版本并关闭“应用执行别名”。
4. **npm 锁定文件是 npm v3。** 使用 npm 7+；当前 npm 10 正常。
5. **两个 `node_modules` 要分别安装。** 根目录用于 `acorn`，`frontends/ink/ui` 用于 Ink UI。
6. **Node 必须进入 PATH。** `workflow/runtime.py` 固定调用 `node.exe` / `node`，不会自动寻找本地便携版。
7. **Python 必须进入 PATH。** `ga_cli/cli.py` 的多数前端命令使用 `"python"` 启动子进程；安装器或用户环境要保证 `python` 可执行。
8. **`ga` 命令需要包安装。** 仅把仓库解压到本地时，`ga` 脚本是否可用取决于 `pyproject.toml` 的 `[project.scripts]` 是否已通过 `pip install -e .` 注册。
9. **安装版不要把 `GA_PROJECT_ROOT` 指向 site-packages。** `ga` 启动器会把调用者当前目录设为工作区；GA 自己的会话、记忆、子代理和日志写入 `GA_DATA_DIR`（Windows 默认 `%LOCALAPPDATA%\GenericAgent`）。
10. **安装脚本必须从 wheel 目录运行解析。** 脚本会先切到 wheel 所在目录，再通过已安装的 `ga_cli.__file__` 定位 site-packages 内的 Ink UI；避免从源码仓库调用时误用仓库的 `frontends/`。

## 9. 常见故障对照

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `ModuleNotFoundError: yaml` | editable 安装未刷新或依赖被手工裁剪 | 重新执行 `python -m pip install -e .` |
| `ModuleNotFoundError: pydantic` | 环境里是 pydantic v1 或未安装 | `python -m pip install "pydantic>=2"` |
| `ModuleNotFoundError: psutil` | 依赖被手工裁剪 | 重新执行 `python -m pip install -e .` |
| `ga ink` 报找不到 `tsx`（安装版） | wheel 安装后未在 site-packages 的 Ink UI 执行 `npm ci` | 运行 `install_release.ps1`，或在该 UI 目录执行 `npm ci` |
| `ga ink` 报找不到 `tsx`（源码版） | 未在仓库 `frontends/ink/ui` 安装 npm 依赖 | `npm install --prefix frontends/ink/ui` |
| `workflow worker did not become ready` / 找不到 `node.exe` | Node 未安装或不在 PATH | 安装 Node 22 并检查 `node --version` |
| `ga web` 报找不到 `streamlit` | 旧入口依赖未安装 | 不建议恢复；仅维护时 `python -m pip install -e ".[legacy-ui]"` |
| `ga gui` 报找不到 `PySide6` | 旧入口依赖未安装 | 不建议恢复；仅维护时 `python -m pip install -e ".[legacy-qt]"` |
| `ga pet` 报找不到 `PIL` | 旧入口依赖未安装 | 不建议恢复；仅维护时 `python -m pip install -e ".[legacy-ui]"` |
| Textual TUI 报找不到 `rich` | 未装 rich | `python -m pip install rich` |
| `launch.pyw` 报 `webview` 缺失 | 未安装 pywebview | `python -m pip install pywebview` |

## 10. 维护规则

- 本文档的“当前实测”以 **2026-10-22** 的本机环境为准：Python 3.12.4、Node v22.17.0、npm 10.9.2。
- 新增第三方 import 时，应同步更新本文档与 `pyproject.toml`。
- 修改 `frontends/ink/ui/package.json` 或 `package-lock.json` 后，应更新 §4.3 的版本表。
- 不要把 `node_modules/`、真实 `llm.yaml`、`mykey.py`、（可能含密钥的）运行日志提交到仓库。
- 若后续改为 PyInstaller / Nuitka / Tauri，本文档仍可作为“运行时基线”保留；打包方案应另建文档，不覆盖本清单。

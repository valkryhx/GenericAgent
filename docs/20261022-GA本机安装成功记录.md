## 5. 本次安装涉及的镜像与网络

第一次尝试失败，是因为官方 PyPI 连接超时：

```text
Connection to pypi.org timed out
```

后续安装成功时，pip 使用了本机已经缓存的依赖，因此没有再次访问 PyPI。

如果目标机器没有缓存，可先设置国内镜像再执行同一安装命令：

```powershell
$env:PIP_INDEX_URL = "https://pypi.tuna.tsinghua.edu.cn/simple"
$env:npm_config_registry = "https://registry.npmmirror.com"
```

这两个环境变量只影响当前 PowerShell 窗口，不会永久修改全局配置。

## 6. 本次安装的已知副作用

因为本次安装目标是 **Anaconda base 环境**，安装器中的：

```text
pip install --upgrade --force-reinstall <wheel>
```

会升级 GA 的公共依赖，本次实际包括：

```text
requests       2.31.0  -> 2.34.2
pydantic       2.12.5  -> 2.14.1
pydantic-core  2.41.5  -> 2.50.1
urllib3        2.6.3   -> 2.8.0
beautifulsoup4 4.12.3  -> 4.15.0
psutil         5.9.0   -> 7.2.2
```

因此 pip 输出了 Anaconda 中其他包的版本冲突提示，例如 Gradio、Streamlit、
a2a-sdk、ragflow-sdk 等。本次 GA 启动正常，但这些提示说明 base 环境不是长期
隔离安装 GA 的理想位置。

后续给其他用户部署时，优先创建专用 venv：

```powershell
C:\anaconda3\python.exe -m venv C:\GenericAgentRuntime
```

再显式指定该环境的 Python：

```powershell
Set-Location D:\dist

$env:PIP_INDEX_URL = "https://pypi.tuna.tsinghua.edu.cn/simple"
$env:npm_config_registry = "https://registry.npmmirror.com"

powershell -ExecutionPolicy Bypass -File .\install_release.ps1 `
  -Wheel .\genericagent-0.1.0-py3-none-any.whl `
  -Python "C:\GenericAgentRuntime\Scripts\python.exe"
```

> 上述 venv 命令是后续推荐的隔离部署方式，**不是本次已执行的安装路径**。

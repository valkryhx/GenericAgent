## 1. 最短可用配置（本机已实测）

配置文件：

```text
C:\Users\drago\.genericagent\settings.json
```

Git Bash 等价路径：

```text
/c/Users/drago/.genericagent/settings.json
```

内容：

```json
{
  "hooks": {
    "Stop": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "python",
            "args": [
              "D:/git_codes/GenericAgent/genericagent/hooks/examples/beep_on_stop.py"
            ],
            "timeout": 10,
            "statusMessage": "Beep"
          }
        ]
      }
    ]
  }
}
```

用途：每个用户请求最终结束时执行一次 beep。`Stop` 绑定的是一次用户回合的终态，不是 GA 内部的 `Turn 1/2/3`，也不是整个 CLI 会话退出。

生效验证：

1. 重启 GA Ink；
2. 发送一条简单消息，等该回合完全结束；
3. 应听到一声 800 Hz、300 ms 的蜂鸣；
4. 在 Ink 输入 `/hooks`，应看到：

```text
source: user
event: Stop
type: command
path: C:\Users\drago\.genericagent\settings.json
```

5. 检查审计：

```text
D:\git_codes\GenericAgent\temp\hooks\events-YYYYMMDD.jsonl
```

其中应有：

```json
{"type":"hook_executed","event":"Stop","status":"success","exit_code":0}
```

## 2. GA 的配置查找路径（逐层）

实现位于：

```text
genericagent/hooks/config.py
  discover_hook_files()
  load_hook_registry()
```

GA 按以下候选路径查找文件。只有**实际存在且是普通文件**的路径会被加载：

| 层级 | source | 路径 | 典型用途 |
| --- | --- | --- | --- |
| 项目 | `project` | `<project>/.genericagent/settings.json` | 团队共享的项目 hook |
| 项目 | `project` | `<project>/.genericagent/hooks.json` | 只放 hooks 的项目文件 |
| 本地 | `local` | `<project>/.genericagent/settings.local.json` | 本机项目覆盖，通常不提交 |
| 用户 | `user` | `~/.genericagent/settings.json` | 对本机所有 GA 项目生效 |
| 用户 | `user` | `~/.genericagent/hooks.json` | 只放 hooks 的用户文件 |
| 显式 | `explicit` | `GA_HOOKS_CONFIG=<path>` | 测试、CI、临时验证；设置后只加载该文件 |

Windows 下：

```text
<project> = D:\git_codes\GenericAgent
~         = C:\Users\drago
```

所以当前项目的完整候选路径是：

```text
D:\git_codes\GenericAgent\.genericagent\settings.json
D:\git_codes\GenericAgent\.genericagent\hooks.json
D:\git_codes\GenericAgent\.genericagent\settings.local.json
C:\Users\drago\.genericagent\settings.json
C:\Users\drago\.genericagent\hooks.json
```

本次实际使用的是：

```text
C:\Users\drago\.genericagent\settings.json
```

## 3. 加载顺序与覆盖语义

实际排序键在 `load_hook_registry()`：

```text
(source_rank, source_path, entry_index)
```

当前 rank：

```text
project settings.json         30
project hooks.json            35
local settings.local.json     40
user settings.json            50
user hooks.json               55
GA_HOOKS_CONFIG               100
```

因此同一事件的 handler 执行顺序是：

```text
project < local < user
```

重要：当前实现是**按文件收集后排序执行**，不是“后层删除前层的同名 handler”。如果想禁用所有已发现配置，用：

```bash
export GA_HOOKS_DISABLED=1
```

如果要完全指定一个配置文件、忽略上述所有默认路径，用：

```bash
export GA_HOOKS_CONFIG="D:/path/to/settings.json"
```

`GA_HOOKS_CONFIG` 存在时，`discover_hook_files()` 直接返回该文件，其他默认路径不会参与。

## 4. 该选哪一层

### 4.1 用户级（推荐用于 beep）

路径：

```text
C:\Users\drago\.genericagent\settings.json
```

优点：

- 所有 GA 项目都能用；
- 不需要修改具体项目；
- 不读取 `.claude/`，不会误触发 CC hooks。

适合：beep、桌面通知、个人日志等跨项目偏好。

### 4.2 项目级

路径：

```text
D:\git_codes\GenericAgent\.genericagent\settings.json
```

适合：项目必须执行的验证、审计、通知。

注意：`.genericagent/` 当前**未被 `.gitignore` 忽略**。若放本机绝对路径或私人配置，容易误提交；要么避免写入该目录，要么先把本地配置文件名加入 `.gitignore`，再只提交脱敏模板。

### 4.3 本地项目覆盖

路径：

```text
D:\git_codes\GenericAgent\.genericagent\settings.local.json
```

适合：当前机器上的项目特化配置。语义上仍会与 project/user 的 handler 一起执行，不是“覆盖并删除”。

### 4.4 临时/测试配置

适合单次验证：

```bash
export GA_HOOKS_CONFIG="D:/git_codes/GenericAgent/temp/hook-e2e/settings.json"
.\ga
```

注意：这个环境变量只对当前 shell/进程生效。之前 `temp/hook-e2e/settings.json` 能响、正常 `.\ga` 不响，就是因为正常启动没有设置它。

## 5. 配置 JSON 的结构

```json
{
  "hooks": {
    "<EventName>": [
      {
        "matcher": "",
        "hooks": [
          {
            "type": "command",
            "command": "python",
            "args": ["C:/absolute/path/to/script.py"],
            "timeout": 10,
            "statusMessage": "Beep"
          }
        ]
      }
    ]
  }
}
```

字段含义：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `hooks` | 是 | 顶层事件对象 |
| `<EventName>` | 是 | 例如 `Stop`、`PreToolUse`、`SessionEnd` |
| `matcher` | 否 | entry 级 matcher；不写表示全部 |
| `hooks[].type` | 是 | `command` / `prompt` / `agent` / `http` / `mcp_tool` |
| `command` | command 必填 | 可执行文件，如 `python` |
| `args` | 否 | 参数数组，推荐 exec form，避免 shell 引号问题 |
| `timeout` | 否 | 秒；默认 command=10，prompt=30，agent=60，http=30，mcp_tool=30 |
| `statusMessage` | 否 | UI 状态文本 |
| `onFailure` | 否 | `continue`（默认）/ `block`；Stop 类事件忽略 block |
| `once` | 否 | runtime 内只执行一次 |
| `async` | 否 | command 后台执行 |
| `asyncRewake` | 否 | command 失败时唤醒后续回合 |

建议始终使用绝对路径：

```json
"args": ["D:/git_codes/GenericAgent/genericagent/hooks/examples/beep_on_stop.py"]
```

因为 command 子进程的 cwd 不保证是你想象中的项目根目录；相对路径容易找不到脚本。

## 6. 本次 beep 配置逐项解释

```json
{
  "hooks": {
    "Stop": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "python",
            "args": [
              "D:/git_codes/GenericAgent/genericagent/hooks/examples/beep_on_stop.py"
            ],
            "timeout": 10,
            "statusMessage": "Beep"
          }
        ]
      }
    ]
  }
}
```

- 事件：`Stop`，一个用户回合最终结束；
- handler 类型：`command`；
- 可执行程序：`python`；
- 参数：GA 自带 beep 脚本；
- 超时：10 秒；
- UI 状态：`Beep`；
- 脚本读取 stdin 后调用 `winsound.Beep(800, 300)`；
- 正常 exit 0、stdout 为空，因此不会污染主对话。

GA 自带脚本：

```text
D:\git_codes\GenericAgent\genericagent\hooks\examples\beep_on_stop.py
```

## 7. 验证配置是否被加载

### 7.1 用 `/hooks`

启动 GA Ink 后输入：

```text
/hooks
```

应显示：

- 已加载文件路径；
- entry / handler 数量；
- 事件与 handler 类型；
- `integrated / contract-only`；
- 配置问题；
- 最近 30 条审计。

如果显示 `0 entries / 0 handlers`，说明没有找到任何配置文件。

### 7.2 用 Python 直接检查 loader

在 GA 仓库根目录执行：

```bash
python - <<'PY'
from genericagent import paths
from genericagent.hooks.config import discover_hook_files, load_hook_registry

print("PROJECT_ROOT=", paths.PROJECT_ROOT)
for source, rank, path in discover_hook_files(project_root=paths.PROJECT_ROOT):
    print(source, rank, path)

r = load_hook_registry(project_root=paths.PROJECT_ROOT)
print("entries=", len(r.entries), "handlers=", sum(len(e.handlers) for e in r.entries), "issues=", len(r.issues))
for e in r.entries:
    print(e.event, e.source, e.source_path, [h.kind for h in e.handlers])
PY
```

当前正确结果应包含：

```text
user 50 C:\Users\drago\.genericagent\settings.json
entries= 1 handlers= 1 issues= 0
```

## 8. 常见不生效原因

### 8.1 把配置放进了 `.claude/`

GA **默认不读取**：

```text
C:\Users\drago\.claude\settings.json
C:\Users\drago\.claude\hooks\beep_on_stop.py
```

这是有意隔离，避免 CC 与 GA 互相触发。GA 要使用自己的：

```text
C:\Users\drago\.genericagent\settings.json
```

### 8.2 只有临时测试配置

`temp/hook-e2e/settings.json` 不会自动加载。需要：

```bash
export GA_HOOKS_CONFIG="D:/git_codes/GenericAgent/temp/hook-e2e/settings.json"
```

或把配置迁到默认路径。

### 8.3 设置了仅对旧 shell 生效的环境变量

`GA_HOOKS_CONFIG` 是进程环境变量。在一个终端 export 后，从另一个终端启动 GA 不会继承它。

### 8.4 相对路径找不到脚本

把 `args` 改成绝对路径。可用：

```json
"args": ["D:/git_codes/GenericAgent/genericagent/hooks/examples/beep_on_stop.py"]
```

### 8.5 配置存在但 JSON 无效

`/hooks` 会显示 issue。也可以直接检查：

```bash
python -m json.tool "C:/Users/drago/.genericagent/settings.json"
```

### 8.6 hook 成功了但听不到

检查：

- Windows 音量和输出设备；
- `winsound.Beep` 是否被系统/驱动静音；
- 是否用了远程桌面或无音频会话。

命令 hook 成功不等于声音一定可闻。审计里 `status=success` 且 `exit_code=0` 表示脚本已正常执行。

## 9. 安全与提交边界

- 用户级配置不要提交到仓库；
- 项目级配置若含本机绝对路径、私人 token 或通知地址，不要提交；
- 配置里不要放真实 API key；
- GA 的 hook 不能绕过 capability / permission / PathACL；
- `PreToolUse` 修改 `updatedInput` 后会重新做权限与 PathACL 检查；
- 云端 hook 与 device forwarding 不在当前复刻范围。

## 10. 一句话结论

GA 的 hooks 通过 **`hooks` JSON 文件**配置，而不是代码开关。最常用的落点是：

```text
C:\Users\drago\.genericagent\settings.json
```

或项目级：

```text
D:\git_codes\GenericAgent\.genericagent\settings.json
```

配置后重启 GA，用 `/hooks` 看是否出现 `1 entry / 1 handler`，再用 `temp/hooks/events-*.jsonl` 验证真实执行。

## 4. 坑与教训（已修正）

1. **`display_queue.put` 必须是 dict**：bridge `_consume_display_queue` 用 `if "system" in item`，放纯字符串会抛 `TypeError`，失败提示根本到不了 UI。真实 LLM 测试才暴露（单测只测了 codec 层 failures）。
2. **多层级 shell/python 传 `\n`、`\r\n`、`\'` 极易被转义破坏**：在 POSIX 正则里 `[\/]` 曾被写成 `[\/]`（丢掉反斜杠，导致 Windows 盘符路径匹配不到）。改动用「heredoc 原样块文件 + Python 精确拼接」，并在改完用 `py_compile` + 真实路径行为断言复核。
3. **O7 让旧测试失效属预期**：旧用例用虚构的 `D:\shots\demo.png` 断言生成占位符；加了存在性校验后必须改为真实临时文件。这是行为改进，不是回归。
4. **FENCE 断言不能看模型回复**：模型会自主 `code_run` 读盘，回复里出现 PINE 不代表自动附图。确定性证据放在 `_extract_image_paths` 纯函数层。
5. **截断提示要真正落地**：`_extract_image_paths_report` 只算 dropped 不够，必须由 `_build_user_content_with_images` 把它拼进 text 才可见。

## 5. 开关与回滚

| 开关 | 关闭后 |
|---|---|
| `GA_CLIPBOARD_TEXT_FALLBACK=0` | 捕获失败静默（旧行为） |
| `GA_IMAGE_AUTO_PATHS=0` | 后端不扫描路径（仅前端附件可用） |
| `GA_IMAGE_AUTO_PATHS_LIMIT` | 覆盖上限 8 |
| `GA_IMAGE_MAX_DIMENSION=2048` | 回到 2048 长边预算 |
| `GA_IMAGE_NOTES=0` | 不输出尺寸说明 |
| `GA_CLIPBOARD_TEXT_TIMEOUT_MS` | 回退读文本超时（默认 2000ms） |
